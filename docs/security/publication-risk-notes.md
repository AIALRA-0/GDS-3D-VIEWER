# Public preview recurrence notes

- The original API has no tenant authentication or production file isolation. Keep it local; public builds must not include or proxy it. Verify POST requests and `/api`, `/review-assets`, `/reference-viewer` and `/legacy.html` are refused at the public origin
- Imported glTF can contain resource URLs. Public parsing must never use the legacy loader on untrusted documents; reject external buffers and all images before geometry conversion. Regress with public URLs, loopback URLs, file URLs and image data URLs
- Flattening a small GDS file can create enormous geometry. Enforce instance, polygon, triangle and depth limits during expansion. A limited design opens the cell directory and never presents partial geometry as complete
- An old canvas's deliberate context shutdown can produce a late context-loss event. Remove old listeners before disposal so replacing a scene does not place an error over the new scene
- A cancelled or replaced import must not overwrite a later file. Invalidate request generations and terminate parser tasks; regression covers a delayed sample fetch followed by a new local import
- Keep template archives, credentials, raw verification traces, local API data and legacy bundles out of the deployment. Check the actual built file list and transferred archive, not only the source ignore rules
- Browser AI keys must remain ephemeral and direct to the explicitly confirmed provider: never proxy them to the website, persist them, include them in exports, follow redirects or echo provider error bodies. Regress with synthetic credentials, intercepted responses, refresh, clearing and cancelled work; keep review screenshots key-free
- Missing library references must not erase valid routing or fabricate dependency geometry. Preserve known facts and mark incomplete previews; regress a synthetic PATH with an absent target and a missing-only cell
- Markdown model output is untrusted: retain the HTML/image exclusion and inert links when changing renderers; regress actual formatting with executable HTML and remote-resource probes
- Interface localization must preserve source cell names, file names and user notes; changing language cancels pending AI requests and resets consent without persisting credentials. Retain legacy review import compatibility when renaming the project
- A renamed viewer's previous public hostname is still a website destination, even though it differs from the current browser origin. Refuse both known preview hostnames before any model fetch, including local/custom deployments; regress the previous alias as well as the current origin
- Source labels and properties are untrusted file data. Collect source metadata once per record, apply text/property/count limits, escape it as text, and never infer electrical connectivity from a label. Only complete text-only cells open the metadata view automatically; expansion-limited designs must retain the smaller-cell directory workflow
- Layer aliases require an explicit user name or numeric mapping. Do not guess process names from layer numbers. Keep aliases separate from geometry, out of browser storage, and distinguish the user-provided name in AI summaries. XML mapping imports must reject document types/entities before parsing and preserve current names on failure
- Inspector tabs must keep the same mounted AI component so hiding a panel cannot create a fresh key or lose cancellation state. Regress tab switching, key clearing, refreshing, consent invalidation and credential-free review export
- GDS block padding is null words after a complete ENDLIB, not permission to ignore arbitrary trailing payloads. Regress zero padding, nonzero trailers, concatenated streams, odd lengths and truncation while retaining existing file/expansion limits
- Exported mappings contain untrusted names. Escape XML characters, canonicalize numeric aliases, refuse conflicting names and enforce the import-compatible 1 MB output budget. Preserve current names on failure and keep AI credentials and layout geometry out of both mapping formats
- Orthographic camera reviews validate projection and zoom while preserving old pose-only files. Hierarchy display has independent depth/row bounds and never invents missing cells; planar ruler geometry must be replaced safely when its point count changes
- Whole-layout reuse needs independent stored-geometry, drawn-triangle, placement, batch and path-character budgets before allocation; sharing vertices must not become unbounded expansion. Mirror templates keep positive instance scales; verify world bounds, transformed picking and layer-index separation. Network protocol errors cannot be repaired by parser limits or by claiming an origin header changed Cloudflare's advertisement

- Palette preference persistence must whitelist names, hex colors and default ID only; current file overrides stay ephemeral. Validate optional review colors before any restored state mutation, retaining legacy files. Regress actual GPU recoloring, CRUD/default refresh, malformed colors, key exclusion and unchanged canvas/camera. Zero spacing must remove intrinsic GDS layer gaps rather than only reduce added offsets, without flattening imported glTF depth.
- Coalesce scene invalidations into one animation-frame draw so initialization effects and camera controls do not repeatedly submit a whole layout. Explicitly flush before PNG export, update world matrices before picking and cancel queued work before renderer disposal. Verify complete instancing, current exported pixels and scene replacement under software rendering; keep parser limits intact.

## Top-cell occurrence UI lessons

Occurrence metadata must remain within existing hierarchy/path budgets and use explicit parent indices: cell names can contain separators. Filtering must retain original triangle and placement identities after GPU index/matrix compaction; otherwise inspection can name a different instance. Synthetic nested cells, transformed arrays, reflected repeated geometry, layer visibility, review restore and actual pixel picking cover these cases. Temporary instance filters are excluded from storage/review exports; no source geometry or visitor key is newly transmitted. All seventeen refreshed screenshots use original demo geometry, with synthetic AI output intercepted and key cleared before capture.

- Palette JSON transfer must use the existing preference whitelist and bounded file size, merge only validated IDs/names/colors and leave current choices intact on malformed input. No key or layout data belongs in the transfer. File-wide display stacks must preserve layer order/thickness across flat and reused cells while remaining explicitly illustrative; camera fitting is not process evidence. Regress planar rotation/middle pan, old review compatibility and actual zero-gap pixels when changing geometry height scaling.
