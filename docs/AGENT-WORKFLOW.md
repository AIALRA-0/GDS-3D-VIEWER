# 1. 项目迭代框架

## 1.1. 接入范围

本项目使用 APCF 智能体项目控制框架（Agent Project Control Framework）0.3.0，规范入口为 [AGENTS.md](../AGENTS.md)，当前正式状态为 [CURRENT.md](../CURRENT.md)

通用规则、脚本、接口、写作标准、设计规则、Profile 和设计案例组件均从维护者的模板副本安装，模板运行输出和历史执行单元没有导入，原项目源码、测试和部署位置保持原位

项目职责见 [PROJECT.md](../.agent-project-control/PROJECT.md)，实现边界见 [ARCHITECTURE.md](../.agent-project-control/ARCHITECTURE.md)，实际设计采用见 [DESIGN.md](../.agent-project-control/DESIGN.md)

## 1.2. 执行入口

从 `AGENTS.md` 读取当前阶段路由，使用控制框架统一脚本创建迭代、用户轮次和一层并行任务，验收结果只保留当前有效表单，正式收口由 `finalize_turn.py` 派生当前状态

启动、动作、并行、收口和发布按 `gate.toml` 的现有入口执行，适用规则、技能和对象摘要发生变化时重新路由并复核实际内容，不能把加载成功当作产品验收成功

常用脚本和参数以 `.agent-project-control/scripts/` 中相应 `--help` 为准，规范正文只在路由指向的位置维护，本页不复制第二套执行规则

## 1.3. 技能和设计

README 技能锁定完整源码树及提交，GitHub 发布技能锁定已安装的完整本地版本及摘要；模板本地旧摘要不匹配当前安装版本时，显式核对后更新本项目锁，不修改模板锁

正式中文内容以控制框架的 Writing v0.1 和 Style v0.1 为当前用户指定权威，README 技能中旧写作接口的冲突要求不替换当前正式入口，README 的专用结构和证据要求继续使用锁定技能

设计采用状态为 PARTIAL，只继承适合版图工作台的规范和参数，已认可的界面及原生参数继续是实现事实来源，模板编辑器和回收站不是本产品功能

## 1.4. 公开与私有边界

当前最小执行清单、验收表单和冻结报告随项目源码保存，原始请求、机器网络清单、账号凭证、并行过程和运行输出留在私有区域并由 Git 忽略

公共网站仍只部署 `apps/web/dist`，控制框架、运行资料、Python API 和原项目入口不会被打包进网站

项目原生构建缓存和 Playwright 输出保持既有工具位置，新的一次性诊断和辅助脚本统一进入控制框架的 `runtime/`

## 1.5. 本项目的必要工具适配

新项目初始化重置设计采用状态，避免继承源项目结论；结构检查保留运行区元数据要求，并将私有测试靶场中的嵌套仓库与本项目规范分开检查；文件树遵守原生 Git 忽略边界，并生成可展开目录视图

项目持续集成检查框架结构、正式规范绑定、设计合同和当前状态来源，产品构建和浏览器回归继续使用原有工具链
