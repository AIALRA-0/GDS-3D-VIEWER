# Interface action design

Frequent actions stay near their target as consistently sized icons: layer visibility, camera modes, notes, colors and export. Each icon has an accessible name plus pointer-hover and keyboard-focus help, dismissible with Escape. Short tooltips also remain visible when hovered. Keep visible text for cell/layer names, tabs, values, first-use actions and AI consent because those convey essential context.

Less frequent choices use native dialogs: export groups review JSON, PNG and mapping JSON/LYP; palettes group built-in choices, CRUD and default selection. Format rows retain names and descriptions, dialogs contain keyboard focus and return it to the triggering control. Layer color swatches directly invoke the browser color picker. Changes update materials and transforms rather than recreating the viewer.

This applies [NN/g progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/): present common actions first and reveal additional choices when needed. [NN/g icon usability](https://www.nngroup.com/articles/icon-usability/) informs retaining text where an icon alone would be ambiguous. [WAI accessible names](https://www.w3.org/WAI/ARIA/apg/practices/names-and-descriptions/), [tooltip behavior](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/) and [native dialog technique H102](https://www.w3.org/WAI/WCAG22/Techniques/html/H102) inform names, focus and keyboard behavior. These are independently implemented patterns, without copied reference-project code or added UI dependencies. Functional and narrow-screen tests establish this implementation's behavior, not a general usability or accessibility certification.

2D and 3D sit adjacent with short visible dimension labels because separate unlabeled icons were ambiguous. Camera presets remain a separate group. Pressed icon buttons use surface contrast without a white inset edge; keyboard focus remains visible. Shared native select fields retain keyboard behavior with one field/arrow style.

Palette browsing uses preview cards and separates editing into a focused view. Numbered color cards offer a large clickable native-picker surface and explicit hex value; save remains a text action. Cell locate actions open a dialog explaining highlight, show-only and hide in the selected top. Dialog headings receive initial focus and return it on close. Statistics comparison explains baseline provenance and count deltas before exposing controls; equal counts do not establish equal geometry.
