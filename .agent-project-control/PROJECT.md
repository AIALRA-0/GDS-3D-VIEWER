# 1. 项目知识

## 1.1. 产品和用户

GDS-3D-VIEWER 是面向版图阅读和展示的公开浏览器预览器，主要入口接受 GDS、GDS2、GDSII 和自包含 glTF/GLB，提供二维和三维查看、图层配置、单元实例定位、测量、审阅记录及可选 AI 讲解

产品能力和限制以 [公开预览说明](../docs/PUBLIC-PREVIEW.md) 为事实来源，用户上手和合成产品展示以双语 README 为公开入口，不在本文件复制预算和完整功能表

## 1.2. 约束

- 公开入口无密码，版图文件留在访客浏览器内，部署只包含公共静态构建
- AI 密钥只存在于当前页面内存，用户确认的摘要由浏览器直接发送至其选择的服务，网站服务器不代理或保存密钥
- 用户已认可成熟界面，本轮设计采用以局部改善为范围，不强制整体替换已认可布局
- 模板源保持不变，安装通用架构时排除模板运行数据和历史执行单元，本项目执行记录从 IT-0001 开始

## 1.3. 工作职责

前端实现继续位于 `apps/web/`，后端继续位于 `apps/api/`，共享合同继续位于 `packages/shared/`，职责和共享修改的锁仍引用 [协作记录](../docs/coordination.md) 和 [文件锁](../docs/agent-locks.md)

APCF 负责执行轮次和规范路由，原生文档负责产品和工具链事实，不建立第二套业务接口或执行历史

## 1.4. 发布和资料

公开仓库为 AIALRA-0/GDS-3D-VIEWER，网站为 [公共预览器](https://gds3d.aialra.online/)，[AIALRA 主页](https://aialra.online/)保留一个入口卡片

当前原始请求、机器网络清单、账号凭证和验收过程留在私有执行面，不进入公开源码或网站目录
