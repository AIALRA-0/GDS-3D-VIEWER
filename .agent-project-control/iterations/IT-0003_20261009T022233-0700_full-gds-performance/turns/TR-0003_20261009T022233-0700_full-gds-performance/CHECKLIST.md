# 1. 当前执行清单

- 【进行中】【CL-01】【执行规范】：当新执行轮次开始时，因沿用旧状态会使执行偏离最新 APCF 合同，必须建立独立记录并遵循当前规则，并以当前规则、表单、并行边界和收口校验通过确认通过
- 【进行中】【CL-02】【全量解析】：当合法 GDS 文件进入解析器时，因固定规模门槛可能拒绝可处理的数据，必须修复解析机制且不以人为规模上限拒绝合法输入，并以用户原文件和合成边界输入完整解析且数据计数一致确认通过
- 【进行中】【CL-03】【完整显示与性能】：当解析结果进入场景构建时，因强制截断或重复展开会丢失内容并增加内存，必须修复完整显示路径并维持可取消的后台处理，并以用户文件全部几何显示、交互可用且性能实测有记录确认通过
- 【进行中】【CL-04】【长期回归】：当修改共享解析和渲染机制时，因仅验证一个样本会遗漏相邻失效面，必须建立可重复的通用回归并完成受影响验证，并以合成规模、异常、取消、二维三维与现有回归通过确认通过
- 【进行中】【CL-05】【公开交付】：当修复需要进入现有公开站点时，因源码与部署不同步或私人资料外泄会影响交付，必须同步必要文档与修复并发布现有入口，并以实际构建、源码回读、正式站点和隐私边界通过确认通过
