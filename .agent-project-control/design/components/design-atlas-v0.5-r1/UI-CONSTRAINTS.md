# UI 修订约束 · v0.5-r1

## 职责与优先级

本文件是 `design-atlas-v0.5-r1` 可选组件的采用合同，不替换共享 Design v0.1，不重编号或改写 D01–D16；只在项目明确采用本组件或对应交互时适用；优先级为：上层安全及宿主约束 → 当前用户明确要求 → 项目已确认约定 → 本组件默认值；历史包中的图标加框建议不再适用于这次明确要求无框的产品界面；历史文件本身保持原样

### UX01｜准确定位修改对象

**原则**：按结构与行为定位控件，不凭“看起来像同一种图标”猜测
**必须**：本次移除 `.pane-head` 标题之前的 `[data-view-grip]` 按钮，不留下透明按钮或占位；保留标题后合理的操作菜单、关闭入口，以及顶栏唯一的左右交换快捷入口；验收检查 DOM 与实际点击，不以隐藏边框代替删除
**例外**：其他项目确实需要拖动把手时，可按其交互合同保留；不能把本轮局部要求扩散为全系统禁止拖拽

### UX02｜符号优先，但不能牺牲辨识

**原则**：产品操作区优先使用易识别的符号，把解释放到二级界面
**必须**：搜索、添加、删除、撤销、缩放、设置等常见图标提供可访问名称以及 hover/focus 说明；纯图标按钮和 ZH/EN 不使用常驻外框；hover、按下、选中和键盘焦点仍必须可见；用户文件名、页面标题和必要状态不是待删除的“文字按钮”
**例外**：陌生动作、不可逆动作、授权确认、空状态首要引导，以及组件教学案例中的按钮层级，允许且通常需要明确文字；不得机械地把所有操作变为无文字图标

### UX03｜尺寸随语境一致

**必须**：同一操作组统一控制高度、图标画布、内边距及基线；窄屏允许文字换行并增加高度，不能截字以维持固定高度；纯图标使用居中的 SVG，不依赖字体符号的偶然基线；密集画布工具栏可采用更紧凑尺寸，触屏应扩大目标并检查相邻误触
**例外**：导航标签、输入框、状态徽标不是同一控件，不强制等宽或全部按钮化

### UX04｜间距使用容器合同

**必须**：相关控件、说明与反馈之间由 `gap` 或明确容器间距维护；不能只依赖会被通用 `p { margin:0 }` 覆盖的段落外边距；默认节奏为 8 / 13 / 21 / 34 / 55 px；案例主体默认 21 px 组间距；测量相邻可见元素的边界，而非只检查 CSS 中是否出现一个数字
**例外**：紧密关联的分裂按钮、输入前后缀、数据单元格可用较小间距；数列是视觉选择，不宣称黄金比例在所有内容上必然最美；可读性、触屏目标、信息层级优先

### UX05｜菜单、提示与对话框分工

**必须**：短选项列表使用非模态菜单或选择器；多字段设置、危险确认使用适当的对话框/抽屉；浮层进入可靠的顶层，检测四边位置、滚动、右键松开、Esc、关闭后的焦点及窄屏；Tooltip 同时支持 hover/focus，并可移入阅读、可关闭；不能只设置浏览器 `title` 就声称完成了自定义提示
**例外**：静态解释可直接显示，不必让每条说明都藏进弹窗；一个简单切换不应被改成多次确认

### UX06｜每个案例一整行，且与自身组件匹配

**必须**：289 项逐项以稳定 ID 登记名称、场景、专属呈现、能力等级和边界；`case-row` 独占内容列宽，不做两列卡片；缺少登记应失败，不能自动回退到“几个灰框”的通用示意；表格、折线图、树形网格、JSON 编辑器等要展示自身结构和对应行为，不得只换标题
**例外**：共享按钮、字段、表格和图表底层实现是正常复用；不要求为每项重复编写基础设施；颜色、排版、语义结构可标为结构/语义示例，不强行添加无意义按钮

### UX07｜展示等级与完成状态分开

**必须**：区分 `interactive`、`native-interaction`、`semantic`、`structural`；一项有案例、一项初始操作已检查、一项通过专项行为测试、生产功能可用，是不同结论；模拟协作、固定 AI 回复、样例耗时必须直接标明；不能把卡片数、节点数或静态图片当成功能验收

### UX08｜图表必须能读数

**必须**：每个有意义的数据点/区域提供准确的名称、值和单位；鼠标与键盘都可查看，提供文本等价数据；图例勾选必须改变对应系列；多选不能实际只显示最后一个系列；提示位置不得越界或被裁切
**例外**：坐标轴、装饰线不必全部成为操作目标；合成地图必须标明并非真实地理数据，不伪装成精确世界地图

### UX09｜画布以真实状态变化验收

**必须**：节点、参数、端口、边、选择与视口分别建模；拖动、端口连线、类型拒绝、断开、删除、复制、多选、撤销/重做、缩放、平移、适应、小地图和 JSON 往返要有实际数据结果；编辑提交失败不改变原图；每个项目画布独立，语言切换不重置图或视口
**例外**：此版为 DAG 节点编辑器，不支持循环执行；运行按钮明确是本地模拟，不等同于 ComfyUI/Dify 或远端模型执行器；其他不需要画布的项目不自动采用它

### UX10｜文件格式对应真实内容与查看器

**必须**：区分 Markdown、CSV、JSON、YAML/TOML、源代码、HTML/SVG、PNG、WAV、diff/log/txt 的内容与行为；格式选择不能仅改扩展名；导出保留真实内容和 MIME；JSON/CSV 的错误保存应拒绝且保留草稿；图片和音频用真实媒体数据，而非图标或说明文本
**例外**：YAML/TOML 可只提供源码、大纲和着色，但必须说明没有完整语法解析器；JavaScript/Python/SQL 查看器默认不执行用户代码

### UX11｜二级操作保留恢复路径

**必须**：关闭设置返回合理焦点；不因切换语言/页签丢失用户输入；导入先验证、确认替换且可撤销；删除若可恢复须展示撤销/回收站路径；未执行保存不能写成“已保存到磁盘”

### UX12｜预览与执行隔离

**必须**：HTML/SVG 使用禁止脚本和网络的沙盒；终端仅允许列明的本地演示命令；算术代码单元不使用 `eval`；上传/协作/AI 样例不得暗中连接外部服务；文件名与字符串输出需转义

### UX13｜响应式不能靠裁切掩盖缺陷

**必须**：检查桌面、平板、320/375 px 窄屏及中英文本；侧栏示例可堆叠，长标签可换行，表格可以局部横向滚动，但页面本身不应横向溢出；画布世界可平移，工具栏、日志、提示和操作入口必须保持可用

### UX14｜兼容数据必须无静默损失

**必须**：共享历史 Profile、D01–D16 和旧包保持字节不变；旧 schema 2 的普通文档/表格仍可打开；旧画布转换保留可表达的连线；无法表达的多输入/循环图明确拒绝并保留原件，不静默丢边；缓存只在数据快照相同时复用，不能把旧撤销历史用于新导入图

### UX15｜验收证据与候选绑定

**必须**：测试记录 HTML SHA、环境、步骤、断言及边界；既检查 DOM，也检查实际数值、文件、状态、焦点、负向拒绝和几何尺寸；目录数量不是替代断言；真实 Windows/浏览器/辅助技术未运行就标 `NOT_RUN`，不能沿用上版 PASS

### UX16｜分发包只有一个当前候选

**必须**：源代码、构建预览、可安装载荷、案例索引和说明的版本一致；新增版本目录，旧包不覆盖；清理旧版安装器和旧测试证据的混入；构建可复现，索引路由由生成器维护，重复应用不重复登记；规范补强通过本合同追加，不擅自改动冻结的共享规范正文
