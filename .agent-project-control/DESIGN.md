# 1. 项目设计采用

共享 D01–D16 正文仅位于 `design/RULES.md`，本文件只维护项目采用和差异

## 1.1. 当前采用状态

- **共享设计基线**：`.agent-project-control/design/INDEX.md`
- **采用状态**：`PARTIAL`
- **当前 Profile**：`tool-workbench-2.3.1`
- **Profile 状态**：`PARTIAL`
- **最近核对**：当前 IT-0001/TR-0001 按真实工作台核对

## 1.2. 实现事实来源

原项目已通过只复制方式参考 AIALRA-TEMPLATE 的中性工具界面，当前实际参数以 `apps/web/src/public/tokens.json` 为权威，组件以 `SelectField.tsx`、`Workbench.tsx` 和 `workbench.css` 为权威，设计说明引用 [界面动作设计](../docs/INTERFACE-DESIGN.md)

## 1.3. 采用范围

工作台的中性主题、对象侧栏、画布、检查器、菜单、提示和对话框按 D01–D06、D09–D11、D13–D16 审查；本轮以用户已认可的布局为基线，只修改有直接交互或可读性依据的局部对象

## 1.4. 参数和差异

- **D02 的数据用色**：版图层颜色表达数据，可编辑配色保留，不将几何数据强制灰度化，验证通过真实层色编辑和明暗主题查看
- **D07 的对象操作**：图形和单元操作已有明确按钮和检查器，用户指定右键不承担平移，当前未采用模板文件右键菜单，验证通过现有选择和实例动作
- **D08 的文件数据模型**：本产品是内存内只读版图预览，无文件树删除和回收站，不把模板文档编辑行为移入产品
- **D09 的布局**：双侧栏已有显示、宽度和位置控制，窄屏使用现有布局规则，不按样板尺寸重新分配成熟画布
- **D12 的内容角色**：当前主内容是版图画布，不增加模板文档编辑器或组件案例主导航

## 1.5. 验证归属

当前设计检查归属于 TR 的 CHECKLIST、TEST 和私有证据，长期失败由 REG 引用原生回归测试，具体共享规则和 Profile 参数仍以原锁定入口为权威
